# ruoyun-li.github.io

Personal academic website of **Ruoyun Li**, M.S. student in Health Informatics at Yale University.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (Jekyll + GitHub Pages).

- **Home page content:** `_pages/about.md`
- **Site settings (name, links, bio):** `_config.yml`
- **Top navigation menu:** `_data/navigation.yml`
- **Profile photo:** `images/profile.png`

See `PUBLISHING.md` for how to publish and update the site.
